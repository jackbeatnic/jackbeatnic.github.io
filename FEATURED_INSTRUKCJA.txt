SZYBKA WYPRZEDAŻ — jeden token, full promo (Shop + OS + Featured)
-----------------------------------------------------------------
  1000 szt. NS A #XXXX po 0.03 w Shop (bez fee).
  OpenSea samo drożej o prowizję 2.5% (0.03 → 0.03077), żeby po fee netto ≈ Shop.
  Featured na górze, metki OS/SHOP/FEATURED, dwa przyciski.
  Listing OS leci przez VPS (aniołek).

  python3 listing/featured_studio.py promo \
    --id 2311 --qty 1000 --pay 0.03 --days 7 --dry-run

  python3 listing/featured_studio.py promo \
    --id 2311 --qty 1000 --pay 0.03 --days 7

  --days = pobyt w Featured I ważność listingu OS (aniołek VPS).
  --hours 12 = krótki Featured (OS i tak min. 1 dzień).
  Cron na kasie zdejmuje kartę po ends_at:  featured_studio.py expire
    (timer: vps/worker/kasa-featured.timer).

  Token NS A musi już być w Shop (po mincie: ns_avax_studio.py po).
  Qty i --pay PODAJESZ TY. --fee 2.5 (%% OS) albo --os-price 0.031 gdy chcesz inną.
  Awaria VPS: --local-os
  Tylko kanały: --no-os / --no-shop / --no-featured

METKI (lewa krawędź miniatury) — AI + Shop + Featured
-----------------------------------------------------
  Strona sama skleja kanały po (collection_id, token_id).
  Nic nie dopisujesz ręcznie do gallery.json.

  niebieski, białe „OS”     = jest listing na OpenSea
  głęboki zielony „SHOP”    = jest w Studio Shop (kasa, BEZ fee marketplace)
  szary „FEATURED”          = karta jest w featured_promo.json

  Widoczne w KAŻDEJ sekcji: AI Art (kolekcja), Shop, Featured.

  Gdy ten sam token jest i na OS, i w Shop — dwa przyciski z prawd. cenami:

    [ Studio shop · 0.03 AVAX ]     ← kasa, bez fee
    [ OpenSea · 0.03 AVAX ]
    „Studio shop · no marketplace fee”

  Cena Shop = najniższy pay_amount z sale_index (t1/t2/t3…).
  Cena OS   = cena z karty Featured (listing promo).
  Przykład: #1800 ma OS 0.03 i Shop 0.03 → oba przyciski.
            #2310 ma OS 0.03 i Shop 0.75 → oba, uczciwe kwoty.
            Base #500 → tylko OS + FEATURED (Shop jeszcze nie obsługuje Base).

  Token z Featured, którego nie ma w 10-ce/galerii AI, i tak widać
  w prezentacji kolekcji (Nature Stories / Flower Stories, właściwy chain).

E. CODZIENNA PROMO WERYFIKACJA OS  (SALE→OOS, poza SYSTEM.md)
-------------------------------------------------------------
  NS A, ten sam token na Shop+OS+Featured → komenda `promo` na górze (szybciej).

  Ten blok: gdy A i B (Base) i/lub INNY id na Shop, osobne ceny.

  python3 listing/featured_studio.py dzien \
    --avax-id AVAX_TID --avax-qty Q --avax-price P \
    --base-id BASE_TID --base-qty Q --base-price P \
    --shop-id SHOP_TID --shop-qty Q --shop-pay P \
    --dry-run

  python3 listing/featured_studio.py dzien \
    --avax-id AVAX_TID --avax-qty Q --avax-price P \
    --base-id BASE_TID --base-qty Q --base-price P \
    --shop-id SHOP_TID --shop-qty Q --shop-pay P \
    --push

  Bez Shop (tylko OS A+B) — odetnij --shop-*:

  python3 listing/featured_studio.py dzien \
    --avax-id AVAX_TID --avax-qty Q --avax-price P \
    --base-id BASE_TID --base-qty Q --base-price P \
    --push

  Co robi `dzien`:
    1. listing_studio.py csv  → JEDEN wiersz / token
       (NIE listing_ops --generuj-dodatkowy — sypie cały supply-bucket)
    2. drukuje:  python3 vps/brama.py listing --csv … --run
       (--os-run odpala bramę od razu)
    3. Shop: ns_avax_studio.py extra  → sku gjb-ns-{id}-t3/t4
       (nie rusza t1 ani t2 0.75; --shop-sync = kasa + check)
    4. present + upsert Featured na górze + push (--push)

  OpenSea CSV: currency PUSTE = native (AVAX / ETH na Base).
  NIE wpisuj „ETH” w wierszu Base.
