Layout — review notes from Google Drive (Grok NFT folder)
==========================================================

Copy both layout review .docx files from Drive into THIS folder
(01 = layout review, 02 = code / fonts / colours improvement proposal).

Source on Drive:
  Grok NFT - Jack Beatnic Gallery Layout

Then in a terminal, from this folder:

  python3 read_docx.py

The extracted text is used to apply the layout fixes and publish them to
jackbeatnic.github.io.
